Questions fréquentes

FAQ technique — réponses aux questions les plus courantes.

Quels sont les prérequis techniques ?
Notre solution est 100% web. Un simple navigateur moderne (Chrome, Firefox, Safari, Edge) et une connexion internet suffisent.
Comment fonctionne l'API ?
Notre API RESTful permet d'intégrer vos données et d'automatiser vos processus. Une documentation complète est disponible avec des exemples en Python, JavaScript et PHP.
Comment sont sécurisées mes données ?
Les échanges sont chiffrés (HTTPS) ; les données les plus sensibles (signalements, accès techniques, clés 2FA) sont aussi chiffrées dans la base. Double authentification, SSO et sauvegardes quotidiennes sont disponibles.
Puis-je exporter mes données ?
Oui, vous pouvez exporter toutes vos données aux formats PDF, Excel, CSV et JSON.
