Activer la double authentification

Egalyx Control — à faire une seule fois, environ 2 minutes. Gardez votre téléphone à portée de main.
1

Installez une application d'authentification sur votre téléphone

Une seule suffit. Elles sont gratuites et fonctionnent sans connexion internet.
FreeOTP Android iPhone
Google Authenticator Android iPhone
Microsoft Authenticator Android iPhone
2

Connectez-vous à Egalyx avec votre identifiant et votre mot de passe

Utilisez l'adresse reçue de votre organisation. Egalyx affiche alors la page « Activer la double authentification » avec un QR code. (Si elle ne s'affiche pas : menu de votre compte → Sécurité du compte → Activer.)
3

Scannez le QR code avec l'application

Dans FreeOTP, touchez l'icône du QR code (en haut) ; dans Google ou Microsoft Authenticator, touchez « + » puis « Scanner un code QR ». Si la caméra ne fonctionne pas, choisissez la saisie manuelle et recopiez la clé affichée sous le QR code.
4

Saisissez le code à 6 chiffres

L'application affiche un code qui change toutes les 30 secondes. Tapez-le dans Egalyx et cliquez sur « Activer ».
5

Conservez vos codes de secours

Egalyx affiche 8 codes de secours une seule fois. Imprimez-les ou notez-les dans un endroit sûr : ils vous permettent de vous connecter si vous perdez votre téléphone.
À chaque connexion suivante : identifiant et mot de passe, puis le code à 6 chiffres affiché par l'application.
Le code est refusé ? Vérifiez que l'heure de votre téléphone est réglée automatiquement. Téléphone perdu ou changé ? Utilisez un code de secours, ou demandez à l'administrateur de votre organisation de réinitialiser votre double authentification ; vous la réactiverez avec le nouveau téléphone. Ne scannez jamais le QR code de quelqu'un d'autre : le compte serait lié à votre téléphone.
