MISE À JOUR EGALYX — CENTRE D'AIDE COMPLET, ASSISTANT, GUIDE ILLUSTRÉ, INTERFACE HARMONISÉE (19/11/2026)

À installer APRÈS « egalyx_aide_assistant ». Aucune migration de base de données.

1. Centre d'aide et assistant
- 163 fiches (52 de plus, en plus des 29 guides illustrés) : chaque page de l'outil a désormais sa fiche (opérateurs, paramétrage de la
  fiche risque, échelles d'évaluation, archives, processus, réglages N2, feuilles de travail, checklists,
  compétences des auditeurs, veille kanban/calendrier/menaces, PCA stress test, grilles qualité,
  documents et formules du super admin…).
- Recherche : vocabulaire courant ajouté (employé, carto, fraude, brancher, inactif, monnaie…).
- Assistant : les questions d'usage passent avant les raccourcis sur les données (« démarrer un audit »
  ne répond plus « audits en cours »). Quand il n'est pas sûr, il propose « Vouliez-vous dire… » avec les
  3 fiches les plus proches au lieu de deviner. Si l'IA externe est activée, elle répond d'après les
  fiches du centre d'aide.
- Mesuré sur 118 questions jamais vues : la bonne fiche est donnée ou proposée 98 fois sur 118 ;
  6 réponses fausses. recette/banque_questions.py contient les 336 questions de test.

2. Guide illustré
- 29 guides (6 nouveaux : lettre de mission, heure et devise, espace opérateur, outils d'audit,
  analyses, super admin) et 94 captures, toutes refaites et annotées.
- Chaque capture existe dans les deux interfaces : le guide montre celle de l'interface de l'organisation.

3. Deux interfaces au choix (super admin → menu à votre nom → Apparence)
- « Interface actuelle » : rien ne change.
- « Interface harmonisée » : mêmes pages, une seule écriture partout (fonds clairs, un seul bleu
  d'action, plus de dégradés ni d'ombres, une seule police, six états lisibles forme + couleur).
  Feuille de style + petit script posés par-dessus les pages : aucune page n'est réécrite.
- « Comparer les deux versions » : aperçu pour vous seulement, sur toutes les pages.
- Les organisations réglées sur l'ancienne « nouvelle apparence » passent en interface harmonisée.
- Variable Render facultative : EGALYX_APPARENCE=harmonisee (défaut des organisations non réglées).

4. Corrections trouvées en parcourant les 444 pages
- Espace opérateur sans permission : boucle de redirections (« trop de redirections ») → page vide + message.
- Exports PDF sans WeasyPrint (absent de requirements.txt) : erreur 500 → version imprimable avec
  bouton « Imprimer / Enregistrer en PDF ».
- Détail d'une sous-action : erreur 500 systématique (méthode inexistante) → corrigé.
- Modifier un plan qualité dont les objectifs sont du texte : erreur 500 → corrigé.
- Logigrammes archivés, gestion des fichiers : erreurs JavaScript quand la liste est vide → corrigé.
- 12 pages qui n'étaient liées nulle part ont maintenant leur lien (menus Audit interne, Pilotage,
  tableau de bord Admin Client, liste des incidents, plans qualité, logigrammes, super admin).
- Formations des auditeurs : coût en devise de l'organisation (et non « € » fixe).

Installation
1. Sauvegarde de la base (pg_dump sur Render).
2. python3 installer_mise_a_jour.py /chemin/vers/le/projet
3. Commitez aussi static/aide/guide/ (dont le dossier harmonisee/) et static/css, static/js.
4. Relancez. Vérification : python3 recette/aide_complete.py, recette/interface_harmonisee.py, recette/pdf_secours.py
