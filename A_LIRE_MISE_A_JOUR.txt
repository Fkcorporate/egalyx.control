EGALYX — CONTENU DES RAPPORTS PAR ORGANISATION (NIVEAU 2)
=========================================================
À installer après « egalyx_rapports_couleurs_client » (présentation des rapports).

1. Nouvelle page « Contenu des rapports » (/organisation/rapports/)
   Accès : administrateur de l'organisation, ou super-admin pour un client ; lien depuis
   Identité de l'organisation. Un onglet par rapport :
   - Rapport d'audit (PDF) et Rapport au comité d'audit ;
   - titre du document (vide : titre habituel) ;
   - sections affichées, avec numérotation recalculée (et sommaire pour l'audit) ;
     le résumé exécutif et la synthèse sont toujours affichés ;
   - introduction et conclusion types, avec des champs remplis à chaque rapport :
     {organisation}, {date}, et pour l'audit {reference}, {mission} ;
   - jusqu'à 4 signataires (fonction, nom facultatif ; sans nom, une ligne pour signer) ;
   - bouton « Rétablir le contenu d'origine ». Chaque changement est journalisé.
   Sans réglage, les deux rapports restent comme avant.

2. Rapport d'audit : le sommaire indique désormais les vraies pages des sections
   (les numéros 3 à 8 étaient fixés à la main). En version imprimable depuis le navigateur
   (serveur sans WeasyPrint), le sommaire s'affiche sans numéros de page.

3. Corrigé : sans WeasyPrint sur le serveur, l'export PDF des incidents et le rapport des
   dispositifs renvoyaient vers une page d'erreur ; ils affichent maintenant la version imprimable.

4. Centre d'aide : nouvelle fiche « Choisir le contenu du rapport d'audit et du rapport au comité ».

INSTALLATION
  python3 installer_mise_a_jour.py /chemin/vers/votre/projet
  git add egalyx templates recette
  git commit -m "Contenu des rapports par organisation" && git push
  (le fichier egalyx/rapport_contenu.py est nouveau : sans « git add », Render s'arrête au démarrage)
