EGALYX — RAPPORTS AUX COULEURS DE CHAQUE ORGANISATION
====================================================

1. Nouveau réglage : Identité de l'organisation → « Présentation des rapports »
   (administrateur de l'organisation, ou super-admin depuis la fiche du client)
   - couleur principale (titres, filets, en-têtes de tableaux, page de garde) ;
     une couleur trop claire, donc illisible sur blanc, est refusée ;
   - mention de confidentialité (« Confidentiel — usage interne », « Diffusion restreinte »…) ;
   - pied de page libre (raison sociale, direction, adresse), à côté du numéro de page ;
   - logo affiché ou non sur les rapports ;
   - aperçu en direct avant d'enregistrer. Chaque changement est journalisé.

2. Rapports concernés (12) : rapport d'audit PDF et rapport complet, rapport au comité d'audit,
   cartographie des risques, KRI/KPI, export des incidents, plan d'action N2, logigramme,
   rapport des dispositifs, organigramme, feuille de travail, audit qualité.
   Sans réglage, chaque rapport garde exactement sa présentation actuelle.
   La lettre de mission garde ses propres en-têtes (réglés par le super-admin).

3. Corrigé : le rapport PDF complet d'une cartographie (toutes campagnes) ne se générait pas
   (« compteurs_net is undefined ») ; il fonctionne de nouveau.

4. Centre d'aide : nouvelle fiche « Mettre les rapports aux couleurs de mon organisation ».

INSTALLATION
  python3 installer_mise_a_jour.py /chemin/vers/votre/projet
  git add egalyx/identite.py egalyx/aide_contenu.py sections/risques.py templates recette
  git commit -m "Rapports aux couleurs de chaque organisation" && git push
