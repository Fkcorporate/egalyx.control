EGALYX — PAGES DE CONNEXION PROPRES ET HOMOGÈNES
================================================

Ce paquet remplace toutes les pages d'accès par un seul modèle :
à gauche le panneau aux couleurs de l'organisation (logo, nom, message, contact),
à droite le formulaire. Sur www.egalyx.com, c'est la marque Egalyx.

Pages concernées (templates/auth/) :
  login_fullscreen, login, connexion_client, client_login, client_inactive,
  forgot_password, email_sent, reset_password, force_change_password, change_password
+ templates/base_auth.html (le modèle commun)
+ templates/auth/_formulaire_connexion.html et _regles_mot_de_passe.html (morceaux partagés)
+ egalyx/connexion_client.py (fournit la marque du client aux pages)

Corrigé au passage :
  - « Rester connecté » ne marchait pas : la case s'appelait "remember" alors que
    le code attend "remember_me". C'est réparé.
  - Les règles du mot de passe (12 caractères, majuscule, minuscule, chiffre,
    caractère spécial, pas d'espace) se cochent en direct pendant la saisie.
  - Bouton « œil » pour afficher le mot de passe sur tous les champs.
  - Les noms de champs et adresses de formulaire sont inchangés : rien à
    modifier dans app.py.

INSTALLATION
  1. Dézippez à côté de votre projet, puis :
       python3 installer_mise_a_jour.py /chemin/vers/votre/projet
     (une copie de sauvegarde des fichiers remplacés est faite automatiquement)
  2. git add templates/base_auth.html templates/auth egalyx/connexion_client.py recette
     git commit -m "Pages de connexion homogènes" && git push
  3. Render redéploie. Vérifiez /auth/login_fullscreen et l'adresse d'un client.

Les couleurs, le message et le contact du panneau se règlent par l'administrateur
du client : Organisation > Identité > Personnaliser la page de connexion.
