EGALYX — INTERFACE HARMONISÉE : BANDES DE TITRE ET TABLEAUX DE BORD
===================================================================

Ne concerne que les organisations réglées sur « Interface harmonisée ».
L'interface actuelle (classique) ne change pas.

1. Bande de titre sur toutes les pages
   - chaque page a maintenant sa bande marine en haut (titre, sous-titre, boutons) ;
   - si le titre est dans l'en-tête de la première carte, c'est cet en-tête qui devient la bande ;
   - pages étroites et centrées : le titre, le lien de retour et le sous-titre sont regroupés dans la bande ;
   - textes, icônes, badges et statuts lisibles sur le fond marine.

2. Tableau de bord d'accueil
   - nouveau bloc « Vos modules » : toutes les informations du tableau de bord classique
     (risques, KRI, logigrammes, veille, incidents, tickets, campagnes, audits, plans d'action,
     contrôle interne N2, PCA), chacun avec son chiffre, son détail, son alerte en rouge,
     une barre d'avancement et un lien vers le module ;
   - seuls les modules ouverts pour l'utilisateur s'affichent.

3. Tableaux de bord des modules
   - les blocs qui n'apparaissaient qu'avec une animation s'affichent tout de suite
     (le tableau de bord Contrôle interne N2 n'est plus vide) ;
   - graphiques : même police, mêmes couleurs, grilles discrètes, légendes en pastilles.

4. Icônes manquantes remplacées (elles étaient vides) : audit, KRI, cartographie,
   évaluation opérateur, super-admin, blog.

5. Centre d'aide : captures de l'interface harmonisée refaites (84 images).

INSTALLATION
  python3 installer_mise_a_jour.py /chemin/vers/votre/projet
  git add static/css/egalyx-harmonise.css static/js/egalyx-harmonise.js egalyx/apparence_tableau.py templates static/aide/guide recette
  git commit -m "Interface harmonisée : bandes de titre, tableaux de bord" && git push
