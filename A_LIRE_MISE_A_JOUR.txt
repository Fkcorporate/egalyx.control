EGALYX — MODULE KRI UNIQUEMENT
==============================

Contenu (seulement le KRI) :
  1. SÉCURITÉ des sources de données (faille : un admin client pouvait lire la base
     des autres organisations) — sources techniques réservées au super-admin.
  2. 12 connecteurs : Jira, ServiceNow, Zendesk, Freshdesk, GitHub, GitLab, HubSpot,
     Odoo, PagerDuty, Datadog, Google Sheets, Airtable + relevé automatique.
     Fiche d'un KRI › « Connecter un outil » (administrateur de l'organisation).
  3. Nouvelle fiche KRI : dernière valeur, jauge des seuils, graphique, historique,
     saisie rapide, collecte automatique, pièces justificatives.
  4. Page /kri/sources : bandeau vers les connecteurs + sources en erreur expliquées
     avec bouton « Supprimer » (mesures conservées).

Fichiers :
  egalyx/__init__.py, egalyx/kri_sources_securite.py, egalyx/kri_connecteurs.py, egalyx/kri_fiche.py
  templates/kri/detail.html, templates/kri/sources/liste.html, templates/kri/sources/form.html
  templates/egalyx/kri_connecteur.html, templates/egalyx/_sources_aide.html
  recette/kri_sources.py, recette/kri_connecteurs.py, recette/kri_fiche.py
  (egalyx/__init__.py fonctionne avec ou sans les autres paquets de la nuit.)

RENDER (Environment) : EGALYX_CLE_CHIFFREMENT (chiffrement des jetons, à créer une fois) :
  python3 -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"

INSTALLATION
  python3 installer_mise_a_jour.py /chemin/vers/votre/projet
  git add egalyx templates/kri templates/egalyx recette
  git commit -m "Module KRI" && git push
