MISE À JOUR EGALYX : CARTOUCHE QUALITÉ DU RAPPORT D'AUDIT
==========================================================

Ce qui change
-------------
Le cartouche qualité (logo | titre | CODE | DATE | VERSION | PAGE « 1 de 5 ») est maintenant
dessiné directement en haut de chaque page, comme le modèle SODEMI, dans tous les rapports d'audit :
  - le rapport PDF élégant ;
  - l'export PDF et le rapport complet PDF (désormais en A4, tableaux qui passent à la ligne) ;
  - les rapports Word (rapport Word, export Word, synthèse Word) : en-tête Word avec champs PAGE / NUMPAGES.
Il n'y a plus qu'une seule numérotation de page (celle de la case PAGE).

Paramétrage (Organisation > Identité de l'organisation > Cartouche qualité)
  - titre du document (sur une ou deux lignes) ;
  - jusqu'à 5 cases libres : intitulé + valeur (CODE, DATE, VERSION, RÉVISION, CLASSIFICATION…) ;
    une valeur peut reprendre l'audit : {reference}, {titre_audit}, {date_rapport}, {annee} ;
  - case PAGE : intitulé et format (« 1 de 5 », « 1 sur 5 », « 1/5 », « Page 1 sur 5 ») ou pas de case ;
  - logo oui/non et sa largeur ;
  - mise en forme : police (Arial / Times), tailles, gras, épaisseur et couleur des traits,
    largeur (page ou zone de texte), cartouche sur la page de garde ou non ;
  - aperçu en direct, et bouton « Aperçu PDF (3 pages) » avant d'enregistrer.
Quand le cartouche est activé, il remplace le papier à en-tête PDF « Rapport d'audit » (plus de réduction du contenu).

Correctif de sécurité
  /audit/<id>/export/rapport-complet vérifie maintenant que l'audit appartient à l'organisation de
  l'utilisateur (avant, un audit d'une autre organisation pouvait être exporté).

Installation
------------
1. Sauvegardez la base (flask sauvegarder).
2. python3 installer_mise_a_jour.py /chemin/vers/le/projet
   (les fichiers remplacés sont gardés dans sauvegarde_maj_<date>/ ; ne pas committer ce dossier)
3. Vérifiez :
   python3 recette/cartouche_qualite.py        → 26/26
   python3 -m pytest -q tests/test_cartouche_qualite.py
4. git add egalyx/pdf_tableaux.py recette/cartouche_qualite.py ; commit ; déploiement Render.
